# V2.8 — Quality Gates e Evidências

## Objetivo

Registrar os quality gates atualmente aplicados ao projeto e a evidência da última execução completa em `dev`.

## Quality gates

O workflow `.github/workflows/ci.yml` executa, nesta ordem:

1. `npm run test` — testes unitários;
2. `npm run test:coverage` — cobertura com V8;
3. `npm run typecheck` — TypeScript sem emissão;
4. `npm run check` — Biome;
5. `npm run build` — build de produção.

A configuração do Vitest exige, para o código incluído na cobertura:

- Lines: 80%;
- Functions: 80%;
- Branches: 80%;
- Statements: 80%.

O workflow E2E `.github/workflows/e2e.yml` executa:

1. instalação do Chromium do Playwright;
2. build da aplicação;
3. execução dos testes Playwright.

O runner E2E possui limite explícito de 15 minutos.

## Jornadas E2E cobertas

Atualmente, a suíte cobre:

- abertura com dados padrão;
- edição e persistência de metadados;
- edição de conteúdo;
- formatação de texto;
- salvar e recarregar;
- desfazer/refazer;
- geração de PDF;
- coalescência de repaginação durante entrada de texto;
- ausência de erros de console no fluxo principal;
- acessibilidade dos controles principais;
- operação por teclado;
- recuperação quando o salvamento falha;
- `prefers-reduced-motion`;
- comportamento com documentos longos.
